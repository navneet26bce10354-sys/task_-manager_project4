# Student Task Manager

A simple Python project for managing student tasks.

## Features
- Add a task
- View tasks
- See task summary
- Save tasks in a text file

## Files
- `main.py` - shows the menu
- `task_manager.py` - adds and displays tasks
- `file_handler.py` - saves and reads tasks
- `validation.py` - checks the status
- `analysis.py` - shows the task summary
- `tasks_data.txt` - stores the tasks

## How to Run
Open the project folder and run:

```bash
python main.py
```
